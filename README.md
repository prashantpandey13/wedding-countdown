# 💕 Prashant & Pratiksha Wedding Countdown

A beautiful, modern wedding countdown website with enhanced aesthetics and performance optimizations.

## ✨ Key Improvements Made

### 🎨 **Aesthetic Enhancements**
- **Modern Design**: Clean, romantic design with gradient backgrounds and glass-morphism effects
- **Better Typography**: Premium font combinations (Playfair Display, Dancing Script, Inter)
- **Smooth Animations**: Elegant hover effects, floating hearts, and smooth transitions
- **Responsive Layout**: Optimized for all devices (desktop, tablet, mobile)
- **Color Scheme**: Romantic gradient palette with soft blues, purples, and pinks

### ⚡ **Performance Optimizations**
- **Lazy Loading**: Images load progressively with smooth fade-in effects
- **Optimized CSS**: Reduced redundancy, better organization, CSS custom properties
- **Efficient JavaScript**: Modular code structure, performance monitoring
- **Resource Preloading**: Critical CSS and JS files preloaded for faster rendering
- **Intersection Observer**: Animations trigger only when elements are visible

### 🖼️ **Image Handling**
- **Lazy Loading**: Images load only when needed
- **Error Handling**: Graceful fallbacks for failed image loads
- **Optimization Guide**: Instructions for compressing large image files (see `optimize-images.md`)

### 📱 **Mobile Experience**
- **Responsive Grid**: Countdown adapts to screen size
- **Touch-Friendly**: Larger touch targets and optimized spacing
- **Performance**: Reduced animations on mobile for better battery life

### ♿ **Accessibility**
- **Keyboard Navigation**: Space bar toggles music
- **Reduced Motion**: Respects user's motion preferences
- **Screen Reader**: Proper ARIA labels and semantic HTML
- **Color Contrast**: High contrast text for better readability

## 🚀 **How to Use**

1. **View the Page**: Open `index.html` in any modern web browser
2. **Optimize Images**: Follow the guide in `optimize-images.md` to reduce file sizes
3. **Add Music**: Replace `your-music.mp3` with your favorite romantic song
4. **Customize**: Edit dates, names, or colors in the code as needed

## 🎵 **Adding Background Music**
1. Add your music file as `your-music.mp3` in the same folder
2. The music button will automatically work
3. Supported formats: MP3, WAV, OGG

## 🎨 **Customization Tips**
- **Colors**: Edit CSS custom properties in `:root` section
- **Fonts**: Change font families in the CSS file
- **Wedding Date**: Update the date in `script.js`
- **Photos**: Replace JPG files with your own (keep same names)
